# Nextcloud PHP WASM integration

## Runtime and API boundaries

`src/runtime/php-loader.js` creates `new PHP(runtimeId)` after `loadWebRuntime`;
`src/runtime/php-compat.js` wraps it for browser request/response conversion and
cookies. The browser loader explicitly requests `extensions: ["intl"]`.
Use dependency versions in `package.json`/lockfile and installed source for exact
API behavior rather than a frozen extension or version inventory.

The raw PHP instance is available as `php._php`; Emscripten FS comes from
`php[__private__dont__use].FS` on the raw instance. `analyzePath` is exposed by our
compat wrapper; do not assume it is a raw PHP method. Inspect the wrapper before
mixing raw filesystem methods and adapter APIs.

Each execution resets PHP globals and PDO connections. SQLite remains a MEMFS
file; do not use `:memory:` or rely on PHP objects surviving another request.
`php.request()` captures session cookies; use it for login/autologin.

## ini, prepend, and occ

Apply ini settings through `setPhpIniEntries` on the raw instance. A separate
project php.ini is not automatically loaded. The loader sets baseline limits;
bootstrap sets the Nextcloud limit and timezone before provisioning. Inspect both
when debugging effective settings.

The browser prepend is `/internal/shared/auto_prepend_file.php`, generated by
`src/runtime/php-prepend.js`. Keep its posix polyfill active before any Nextcloud
code; the runtime lacks native posix. Preserve the spawn handler's graceful
handling of unavailable external binaries; it does not provide real subprocesses.

SAPI is `wasm`. Use `buildOccScript` from `src/runtime/install-script.js` for
in-process occ: argv/env setup, `REQUEST_URI` unset, chdir, and `console.php`.
Do not require `occ`: its shebang breaks `strict_types`. The web path must retain
`REQUEST_URI` so the patched CLI detector does not misroute HTTP requests.

## Networking and persistence

PHP curl is not intercepted by JS `globalThis.fetch` blockers. Outbound PHP HTTPS
uses `tcpOverFetch`, its generated CA, and `phpCorsProxyUrl`. Keep `openssl.cafile`
and `curl.cainfo` aligned with the active CA; preserve the configured proxy policy.
Browser addon downloads and PHP requests are separate paths.

The loader initializes filesystem journaling before bootstrap. Mutable Nextcloud
config/data and `/persist` survive reload through IndexedDB; OPcache is separately
journaled by PHP version. Clean boot clears and restarts both paths. Refer to
`fs-persistence.js` for journal roots rather than assuming all state is `/persist`.

Use the existing unit tests for generator/adapter behavior. For changes to boot,
login, or networking, rebuild the worker and check the affected browser flow.
The Node spike is useful for PHP diagnostics, but cannot replace browser checks.
